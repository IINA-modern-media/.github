# IINA — Modern Media Player With Picture-in-Picture and Support for All Formats

## About IINA

IINA provides a modern media player for macOS with support for virtually every video and audio format — MP4, MKV, AVI, MOV, FLV, WMV, MP3, FLAC, AAC, and dozens more. IINA combines the powerful MPV playback engine with native macOS interface (Swift), picture-in-picture mode (watch videos while using other apps), online subtitle search (OpenSubtitles integration), touch bar controls, and fully customizable UI. IINA enables users to play any media file with hardware-accelerated decoding, audio filters, video filters, and chapter navigation. IINA is open source, completely free, and trusted by millions of macOS users who need a modern alternative to VLC or QuickTime.

## Deep Dive — Modern macOS Media Player

Playback engine — mpv (libmpv) with hardware decoding (Videotoolbox on Apple Silicon, Intel Quick Sync)  
Format support — video (MP4, MKV, AVI, MOV, FLV, WMV, WebM, MPEG, OGV, M4V), audio (MP3, FLAC, AAC, OGG, WAV, M4A, AC3, DTS, OPUS), subtitles (ASS, SRT, PGS, SSA, VTT)  
Picture-in-picture (PiP) — floating video window on top of all other applications, resizeable, click-through controls  
Online subtitles — search and download subtitles from OpenSubtitles.org, automatic language detection, sync delay adjustment  
UI features — dark/light theme auto-switch, customizable colors, thumbnail preview on seek, force touch seek, touch bar scrubbing, interactive playlist, music mode (album art)  
Performance — native Apple Silicon (M1/M2/M3) support, Metal rendering, low battery impact

## Quick Reference for IINA

| Operation | IINA Action |
|-----------|--------------|
| Enter full screen | Cmd+F |
| Enter picture-in-picture | Cmd+Shift+P |

| Volume up/down | Cmd+Up / Cmd+Down |

| Show playlist | Cmd+Shift+L |

| Take screenshot | Cmd+S |
| Toggle always on top | Cmd+Shift+A |
| Open preferences | Cmd+, |
| Quit IINA | Cmd+Q |
